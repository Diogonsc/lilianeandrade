# TikTok Monetizado

Landing page do treinamento online de estratégia e monetização no TikTok, com [Liliane Andrade](https://lilianeandrade.com.br).

![Captura da landing page TikTok Monetizado](public/images/image-readme.png)

Treinamento 100% online e prático: estruturar o perfil, criar conteúdos estratégicos, conquistar seguidores e entender os caminhos de monetização na plataforma.

## Stack

- [Next.js](https://nextjs.org) 16
- React 19
- Tailwind CSS 4
- TypeScript

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
